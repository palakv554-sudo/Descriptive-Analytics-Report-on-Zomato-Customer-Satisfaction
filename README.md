# 📊 Data Analytics Portfolio

Welcome to my Data Analytics Portfolio! This repository showcases two projects focused on customer satisfaction analysis and retail sales insights using data analysis and visualization techniques.

### 🍽️ Project 1: Zomato Customer Satisfaction — Descriptive Analysis
Analyzed restaurant ratings, customer votes, location performance, popular menu items, and menu pricing to identify patterns in customer satisfaction and restaurant performance.

Developed an interactive sales dashboard featuring Total Sales, Total Orders, Sales Trends, and Sales by Product Category, with a **Region filter** to explore sales performance across different regions.
